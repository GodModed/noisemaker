# noisemaker
Play noise through an ESP32.

## Current State of Project
- [x] Waiting for parts to ship
- [x] Run test code on esp32
- [ ] Write sample code to play a tone on speaker

## Required Parts
| Part | What it does | How many to use |
|---|---|---:|
| **ESP32 board** | Connects to Wi-Fi, receives commands or audio, and generates the digital audio signal. | 1 |
| **MAX98357 amplifier** | Converts the ESP32’s digital audio into power that drives the speaker. | 1 |
| **4Ω, 3W speaker** | Produces the sound. | 1 |
| **Breadboard** | Holds the parts and connects them without soldering. | 1 |
| **Jumper wires** | Connect power, ground, and the three audio signals between boards. | 5 |
